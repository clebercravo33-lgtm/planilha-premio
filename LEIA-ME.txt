# PWA — Premiação Grupo Nico (v79)

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie **todos os arquivos e a pasta `icons`** para a raiz do repositório GitHub.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e salve.
5. Abra o endereço HTTPS publicado. No celular, use o menu do navegador → **Instalar app** ou **Adicionar à tela inicial**.

O PWA usa `index.html`, `manifest.json`, `sw.js` e os ícones. O cache offline melhora após a primeira abertura com internet; bibliotecas externas e sincronização Supabase podem exigir conexão.
