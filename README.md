# Premiação Grupo NICO — PWA

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie **todos os arquivos e a pasta `icons`** para a raiz do repositório GitHub.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação e abra o endereço do GitHub Pages no celular.

## Instalar no celular
Abra o endereço publicado usando Chrome ou outro navegador compatível. Use o menu do navegador e escolha **Instalar app** ou **Adicionar à tela inicial**.

## Observações
- O PWA precisa ser publicado em HTTPS (GitHub Pages fornece HTTPS).
- O aplicativo mantém os dados locais no navegador. Para sincronizar entre aparelhos, configure o Supabase dentro do app.
- O Service Worker guarda a estrutura principal do aplicativo para permitir abrir a interface quando estiver sem conexão. Bibliotecas externas (planilhas, gráficos e PDF) podem precisar de internet.
- Primeiro acesso: `admin` / `admin123`. Troque a senha após entrar.
